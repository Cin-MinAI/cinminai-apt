# cinminai-apt

The signed apt repository of [Cin-MinAI](https://github.com/Cin-MinAI), served by GitHub Pages at
**https://cin-minai.github.io/cinminai-apt**.

Cin-MinAI systems use it automatically; there is nothing to do by hand. The packages are signed with the
Cin-MinAI archive key, which ships in the `cinminai-archive-keyring` package:

    Cin-MinAI Archive Key
    7EA7 4B93 128A A958 65E2  BA39 77CA 19E6 2644 70F6

The key lives only on an offline stick, and every release is signed by hand (PLAN D72). The public key is
also here: [`cinminai-archive-keyring.asc`](cinminai-archive-keyring.asc).
